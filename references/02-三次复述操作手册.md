# 02 · 三次复述操作手册

三次复述是这套方法唯一不可省的部分。书里的定义：
- **第一次**：讲给自己（第 10 章）
- **第二次**：讲给别人，真实场景（第 14 章）
- **第三次**：讲出原创（第 23 章）

下面给的是可执行脚本——照着念都行。

---

## 第一次复述 · 讲给自己

### 时间安排

| 时段 | 时长 | 动作 |
|---|---|---|
| T0 | 20 分钟 | 读/看材料，只求结构，不求细节 |
| T0+20 | 5 分钟 | **合上材料**，凭印象讲（可录音/可写） |
| T0+25 | 3 分钟 | 喝口水，写下刚才卡住的地方 |
| T0+28 | 10 分钟 | 边讲边问，逐条填"为什么" |
| T0+38 | 5 分钟 | 加自己的观点：这让我想到什么？和什么冲突？ |

### 第一阶段的脚本

> 开口就这么说（对着空气或手机录音）：
>
> 「我要讲的是____。它主要想说三件事：第一____，第二____，第三____。其中我觉得最关键的是____，因为____。」

规则：
- **不看材料**
- **允许说错**
- **必须讲完**，不许中途回去翻书

### 第二阶段的提问清单

每讲完一段，问自己：

1. 刚才那句我是**背下来**的，还是**想明白**的？
2. 我跳过了哪一步？（通常是从"因为"直接跳到"所以"）
3. 如果对方反问「凭什么」，我拿得出证据吗？
4. 这个概念和我已经知道的哪个东西是一回事？哪个不是？
5. 有没有哪个词我一直在用，但没定义过？

### 第三阶段的三个句式

- 「这让我想到____，因为它们在____上是同一个结构。」
- 「这和我原来相信的____冲突，冲突点在____。」
- 「如果这条成立，那我以前做的____就错了。」

### 产出：卡壳记录表

| # | 卡在哪一句 | 类型 | 处置 | 复述二遍是否通过 |
|---|---|---|---|---|
| 1 | | 记忆空洞 / 逻辑断点 / 证据不足 / 术语依赖 | | |

## 第二次复述 · 讲给别人

### 讲给谁：听者选择的硬标准

| 听者 | 诊断力 | 说明 |
|---|---|---|
| 同领域专家 | 低 | 术语自动通融，你的漏洞会被"懂行"掩盖 |
| 相邻领域 | 中 | 能接住部分概念，术语滥用会被抓 |
| **完全外行（首选）** | **高** | 术语一出现就断线，必须真讲机制 |
| 12 岁以下孩子 | 最高 | 抽象词全部失效，只能靠具体与类比 |

原书的标准是「**几岁的小孩也能明白你在说什么**」（前言引费曼）。达不到这个标准，就是没讲清。

### 准备：提纲 + 三个问题

复述前写在一张纸上（不许超过一页）：

```
【我要让他听懂的一件事】一句话
【三条主干】
  1.
  2.
  3.
【一个类比】他熟悉的东西 → 我要讲的东西
【我希望他问的三个问题】
  Q1. （这是我自己的薄弱处）
  Q2.
  Q3.
【我可能被反驳的点】先想好怎么答
```

原书说得很直接：分组讨论**容错率很小**，必须提前设计提纲和互动问题（第 14 章）。

### 现场脚本

**开场**（把对方身份设定清楚）：

> 「我用五分钟给你讲个东西，你随时打断我。讲完你告诉我：哪一句你没听懂，哪一句你不信。」

**讲的过程中**，每讲完一条主干，停 3 秒，问：

> 「这条你听懂了吗？用你自己的话说一遍给我听。」

> 对方复述不出来 —— 不是你讲得不清楚，就是这条本身没结构。两者都要回去改。

**收尾必问三句**（这是第二次复述的真正目的）：

1. 「哪里你觉得不对劲？」
2. 「如果我说的是错的，你最怀疑哪一条？」
3. 「你听完之后，能用一句话说出我说了什么吗？」

第 3 句是硬指标。**对方说不出，等于没讲成。**

### 处理异议的三步（原书第 14 章）

拿到否定后别急着辩，先分三类：

| 异议类型 | 判断依据 | 应对 |
|---|---|---|
| 讲法问题 | 对方说"听不懂/太绕" | 换类比、换顺序，内容不动 |
| 内容问题 | 对方说"这条不对/我有反例" | 记入反证清单，进第 5 阶段 |
| 立场问题 | 对方在争价值判断而非事实 | 标注为"立场分歧"，不当作知识错误 |

原书的态度：**"越尖锐越好，越矛盾越好"**——因为差异意味着问题。

### 没有真人听者时

按第 13 章的四型自演，但**必须标注**：

```
【模拟复述 · 未经真实检验】
模拟角色：质疑者
我预判的三个反驳：…
我的回应：…
未验证部分：对方是否真的会这样反驳
```

不标注这一条，等于把排练当成了演出。

## 第三次复述 · 讲出原创

### 目标不是"讲得更好"，是"讲出别人没说的"

前两次复述在解决"我懂没懂"。第三次要回答：**我能不能解释、解决、预测**（第 23 章）。

### 三个入口

1. **预测入口**：如果这套说法成立，接下来应该发生什么？给出一个可观察的信号。
2. **反例入口**：我在什么条件下会看到它失效？这个条件可测吗？
3. **连接入口**：它和我已知的哪个领域是同一个结构？那个领域的什么结论可以搬过来？

### 检验：能不能被证伪

写下你的原创点，然后问：

- 什么观察结果会让你放弃它？
- 这个观察现在做得到吗？

**两个都答不出** → 这不是观点，是修辞。必须如实标注：

```
【修辞性观点，未经检验】
```

### 原书给的顺序

费曼五条建议（第 22 章）是个闭环，第三次复述在其中排第四：

记核心要素 → 大幅整理 → 结构化归纳 → **输出发布** → 简化吸收记忆

注意：**输出排在简化之前**。先讲，再简化；不是先简化，再讲。因为简化的判断标准来自讲的效果。

## 三次复述的对照表

| | 第一次 | 第二次 | 第三次 |
|---|---|---|---|
| 对象 | 自己 | 真实听者 | 同行/公众 |
| 目的 | 暴露缺口 | 拿到异议 | 建立原创 |
| 允许不完整 | 是 | 否 | 否 |
| 关键动作 | 合书 + 记卡壳 | 设计提纲 + 索异议 | 给可检验预测 |
| 失败信号 | 讲不出骨架 | 对方说不出你讲了什么 | 说不出"若成立则观察到 X" |
| 对应章节 | 第 10 章 | 第 14 章 | 第 23 章 |
