# 03 · 自检表与失败模式

---

## 一、七道闸门（逐项判定）

每道闸门只有两种结果：**通过** 或 **打回**。没有"基本通过"。

### G1 · 目标闸门

判定问题：

- [ ] 目标能用一句话说清，且**能形容**（不是"学好 X"）
- [ ] 有量化验收标准（数量/质量/时间三选一以上）
- [ ] 以现有基础够得着（能说出"凭什么够得着"）
- [ ] 能说出达成后具体获得什么
- [ ] 有验收日期
- [ ] 五原则里至少 4 条能答，**重点性原则必答**

打回信号：任何一个问题只能说"大概""差不多""以后"。

---

### G2 · 来源闸门

- [ ] 至少 3 个来源
- [ ] 每个来源标了等级（原始 / 权威二手 / 社区）
- [ ] 至少 1 个是原始或权威二手（全社区来源不算过）
- [ ] 三源冲突处已单独记录
- [ ] 结构图能画出 3–4 条主干，每条主干能配一个具体形象

打回信号：所有来源都是同一个作者的转述；或结构图画成了目录摘抄。

---

### G3 · 第一次复述闸门

- [ ] 合书讲完过一遍，没有中途翻资料
- [ ] 讲出了骨架（三条主干都在）
- [ ] 卡壳点记了，且**分了类型**
- [ ] 每个卡壳点都有处置动作（不是"回头再看"）

打回信号：卡壳记录是空白——那不是没卡壳，是没真讲。

---

### G4 · 第二次复述闸门

- [ ] 有听者（真实，或已标注"模拟"）
- [ ] 听者不是同领域专家（除非另有外行听者）
- [ ] 复述前写了提纲与三个预期问题
- [ ] 收到了至少 1 条**异议**（纯赞美不算）
- [ ] 听者能用自己的话复述出你说的内容

打回信号：对方全程点头，说"讲得挺好"。这说明你讲的是共识，不是知识。

---

### G5 · 反证闸门

- [ ] 反证 ≥ 3 条
- [ ] 类型至少覆盖 2 类（数据 / 逻辑 / 时效 / 权威）
- [ ] 至少有 1 条是「若它成立，我就错了」级别
- [ ] 每条反证都有出处（不许"我觉得可能有人反对"）

打回信号：三条反证全是"可能有人不同意"这种软话。

---

### G6 · 简化闸门

- [ ] 一句话版本 ≤ 40 字
- [ ] 一句话里**零术语**
- [ ] 给外行念一遍，他能复述大意
- [ ] 外行追问"为什么"时，有第二层可讲
- [ ] 能说清哪些是核心、哪些是支撑、哪些是装饰，并给出分档理由

打回信号：一句话很顺，一追问就空——这是口号，不是简化。

---

### G7 · 原创闸门

- [ ] 有一个原文没有的东西：新问题 / 新连接 / 旧框架的盲区
- [ ] 附了可检验预测（若成立，应观察到 X）
- [ ] 或已明确标注「修辞性观点，未经检验」

打回信号：所谓原创只是把原文换个说法。

---

## 二、收敛判定（何时停手）

这套方法最大的副作用是**无限深挖**：总觉得还有没懂的，于是一直补前置知识，永远不交付。

给一个可算的停止规则。跑完两轮后统计：

```
核验通过率   = 已外部核实的条目数 / 总条目数
反例产出率   = 本轮新增反例数 / 本轮检查条目数
```

判定：

| 核验通过率 | 反例产出率 | 结论 |
|---|---|---|
| ≥ 0.60 | ≤ 0.35 | **停止施压，交付** |
| ≥ 0.60 | > 0.35 | 还有真问题，再跑一轮反证 |
| < 0.60 | 任意 | 结构没搭好，回阶段 2 |

阈值需按领域自标定（工程类可更严，人文类可更宽），但**必须显式写出来**，否则等于没有规则。

## 三、十二种失败模式

| # | 失败 | 具体表现 | 纠正动作 |
|---|---|---|---|
| 1 | 抄书当复述 | 讲的句子和原文几乎一样 | 合书，换自己的词，禁止用原文的形容词 |
| 2 | 术语搬运 | 用"赋能/闭环/范式/底层逻辑"撑场面 | 每个术语换成一句大白话；换不掉就是没懂 |
| 3 | 只找正面证据 | 越查越确信，越确信越不查 | 强制先写 3 条反证再看结论 |
| 4 | 顺畅当懂 | 「一下就通了」 | 追问：能预测一个没见过的情况吗 |
| 5 | 跳过目标 | 打开书就读 | 回阶段 1，先写目标卡 |
| 6 | 听者选错 | 只讲给同行 | 换一个完全外行，重讲 |
| 7 | 无限深挖 | 永远在补前置知识 | 用收敛判据叫停 |
| 8 | 简化成口号 | 一句话很顺，追问就空 | 必须能接住第二层"为什么" |
| 9 | 把模拟当验证 | 自己在脑子里演一遍就算讲过了 | 标注「未经真实检验」 |
| 10 | 目标中途调低 | 遇挫就把标准降到刚好能做到 | 原书第 6 章明确禁止：不许人为调低难度 |
| 11 | 收集即学会 | 收藏、划线、做笔记就算学完 | 笔记不是产出，卡壳记录才是 |
| 12 | 用权威替代论证 | 「某某说的」当理由 | 权威只在当下条件内成立；要问适用边界 |

## 四、三分钟自检（来不及跑全流程时）

只有三分钟，就答这五句：

1. 我学它要解决什么**具体问题**？
2. 我能用**一句话**讲清它是什么吗？（不许术语）
3. 它什么时候**不成立**？
4. 如果有人反对，他最可能从哪**打**我？
5. 我现在**还不敢讲**的是哪一段？

第 5 题答不出来，通常是自欺；能答出来，就已经知道下一步该干什么。
