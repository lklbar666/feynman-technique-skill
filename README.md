# 费曼学习法 · 执行器（feynman-technique）

把「学一个东西」变成可以验收的八个阶段。验收标准只有一条：**能不能不看资料、不用术语，讲到外行听懂，并接住追问。**

## 这是什么

不是读书笔记，是把《费曼学习法》（尹红心、李伟，江苏凤凰文艺出版社 2021）里的原则，改写成可执行、可打回的流程。

- 八个阶段：受理 → 立标 → 结构化 → 第一次复述 → 第二次复述 → 回顾找反证 → 简化 → 第三次复述出原创
- 七道闸门：每阶段一个，答不上来就打回，不许"基本通过"
- 三份模板：讲解卡 / 卡壳记录 / 反证清单
- 一条收敛判据：防止"永远觉得自己没懂"的无限深挖

## 三条边界

1. **这本书不是费曼写的。** 是中文编著，作者尹红心、李伟。书中第 19 章自己写明：费曼从未把方法理论化，框架由追随者整理。
2. **"内容留存率 90%"没有原始出处。** 书中多次引用，但未给文献；学习金字塔的具体百分比在该电子书中图缺失。本技能不引用任何具体留存率百分比。
3. **书中转引的统计（68% / 0.1% / 5 艾字节等）均为二手。** 引用时须标注。

把二手数字讲成定论，就是在制造这本书本身反对的"假知识"。
